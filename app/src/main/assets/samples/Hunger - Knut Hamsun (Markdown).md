# Hunger - Knut Hamsun (Markdown-versjon, prøve)

## Oversettelse og forord
Sagt i korthet: romanen Hunger av Knut Hamsun utkom første gang i deler i perioden 1888–1890. Den var med på å grunnlegge den moderne norske lyriske prosaromanen.

## Utvalg av kapitler
- **Kap. 1**: Innledning, sulten i Kristiania, møtet med kongen.
- **Kap. 2**: Tur til Akershus, møtet med den røde frøken.
- **Kap. 3**: Søster og søsterhusbesøk, savnet av mor.

```
«Jeg var sulten, jeg var sulten hele tiden,» sier fortelleren.
```
